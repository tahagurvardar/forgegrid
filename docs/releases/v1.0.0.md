# ForgeGrid v1.0.0 — prepared release notes

Prepared for a public portfolio release; this document creates no tag or GitHub Release. Final eligibility is recorded in [release-audit.md](../release-audit.md). ForgeGrid is a distributed execution engine with CI-style static DAGs, not a full hosted CI replacement.

## Implemented and verified scope

- Go Control Plane and outbound gRPC/Protobuf workers, stable IDs/process sessions, heartbeat liveness and capacity reservations.
- Immutable attempts, monotonic fencing, renewable execution leases and ACK-gated monotonic guards.
- Lease-expiry crash recovery, bounded infrastructure retry, stale-result rejection and duplicate-winner idempotency.
- Trusted-local Docker argv execution, correlation labels, cleanup attempts and returning-worker orphan reconciliation.
- Static DAG validation, parallel fan-out/fan-in, transactional release, transitive SKIPPED propagation and independent branches.
- Job/pipeline cancellation, per-attempt execution timeout and terminal pipeline aggregation.
- Sequenced stdout/stderr persistence, duplicate-safe chunks, resumable SSE and bounded browser logs.
- React/TypeScript/Vite console: overview, DAGs, jobs, worker sessions, attempts/fences/deadlines, trace links and retained LOST/recovery history.
- OpenTelemetry → Collector → Jaeger tracing, bounded-cardinality Prometheus metrics and structured logs, isolated from execution authority.
- Real PostgreSQL concurrency/rollback tests, Docker/process-crash tests, telemetry-outage checks and real browser recovery.

## Signature demo

worker-b attempt #1 → heartbeat loss → offline without immediate transfer → lease expiry → LOST → fresh attempt/higher fence → worker-c success → old delayed completion rejected. The successful retry releases dependents; old LOST history remains in the console.

The final audit corrected terminal-SKIPPED cancellation, malformed SSE handling, dependency advisories and verification/export-path issues without redesigning ownership.

## Known limitations

Single Control Plane, no HA/scale or production-ready public deployment claim. Trusted workloads, no authentication/TLS or hostile multi-tenant sandbox. At-least-once physical execution can overlap; fences do not protect external side effects. Inaccessible daemons may retain old containers; cancellation cannot guarantee remote shutdown. Logs/traces can be lost; no durable spool/total log retention; Jaeger is transient.

Static DAGs are bounded to 128 jobs/2,048 edges. Submission idempotency, DRAINING, dynamic/matrix DAGs, expressions, fail-fast, artifacts, secrets and integrations are not implemented. Network/PG failover coverage is not exhaustive. [MIT license and dependency notices](../licensing.md).
